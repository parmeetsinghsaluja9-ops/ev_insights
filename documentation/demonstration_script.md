# Demonstration Video Script (target 8-10 minutes)

Record screen + voice. Use the live GitHub Pages site once published.

| Time | Screen | Say |
|---|---|---|
| 0:00 | Title slide / site hero | "Hello, I'm [name]. This project analyses Superstore sales and profit with Tableau. I'll show the data, dashboard, story, performance tests and the website." |
| 0:45 | Folder + `data/original` | "The source is a public Superstore CSV with 8,399 order lines from 2009 to 2012. I kept the original unchanged and verified it with a hash." |
| 1:30 | `data_quality_report.md`, `clean_data.js` | "A Node.js script fixed region and province typos, converted dates and added derived fields. No rows were removed." |
| 2:30 | Excel workbook | "The workbook has the dictionary, cleaned data, KPI formulas, and analysis sheets. Formulas were checked against an independent recalculation." |
| 3:30 | Tableau: calculated fields | "These are the calculated fields: profit margin, discount band, distinct orders, loss share, a LOD, and a parameter." |
| 4:30 | Tableau dashboard | "KPIs on top, trend, category profit, map, discount and ship mode. Click Furniture - everything filters. Now the phone layout: it stacks for responsiveness." |
| 6:00 | Tableau story | Walk through the 6 points; read each takeaway sentence. |
| 7:30 | Performance test plan + results | "I tested four factors: data amount, filters, calculated fields, and number of charts. Here are my measured results [or: results pending]." |
| 8:30 | Website | "The site embeds the published dashboard and story, works on mobile, and shows a notice if a link is missing." Resize browser to show responsiveness. |
| 9:30 | Close | "Key finding: Furniture, truck shipping and high discounts coincide with thin margins. Recommendations are on the site. Thank you." |

Tips: zoom to 125%, hide bookmarks/notifications, rehearse once, do not read numbers you did not measure.
